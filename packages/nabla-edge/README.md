# nabla-edge (minimal package)

Install on an **existing** Raspberry Pi OS or Linux system to join **Nabla Net**.

Intended contents (to be filled by Edge):

- `vpn-mode` / nabla-net helpers (cable / ap)
- Tailscale assist + subnet advertise where appropriate
- Firstboot / branding hooks (light)
- Apt source snippet for Nabla packages

This is **not** a full OS image — see `images/` for Nabla OS.
