# Nabla OS images

Build from **official** bases; inject the Nabla layer; publish `.img.xz` + SHA256 on nabla.net/linux.

| Flavour | Base | Folder |
|---------|------|--------|
| Nabla OS Pi | Raspberry Pi OS | `pi/` |
| Nabla OS Desktop | Linux Mint | `desktop/` |

Do not fork kernels. Base OS updates stay on Pi / Mint / Ubuntu apt; Nabla packages stay on the Nabla apt.
